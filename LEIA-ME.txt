JUH QUIZ TREND - ARQUIVOS PARA GITHUB

ARQUIVOS:
1. campanha.py
   - E o arquivo que voce altera quando surgir uma nova tarefa, hashtag ou tema.
   - Escolha modo: normal / hashtag / tarefa.
   - Coloque titulo, hashtag, gancho, fechamento e as 5 perguntas.
   - Cada tema dentro de QUIZZES gera um MP4.

2. gerar_juh_quiz_trend.py
   - Nao precisa editar para cada campanha.
   - Gera o visual azul-marinho + azul neon + ciano + amarelo + roxo/rosa,
     inspirado na identidade visual Juh Quiz enviada.

3. requirements.txt
   - Dependencias Python.

4. .github/workflows/gerar-juh-quiz-trend.yml
   - Workflow para rodar manualmente no GitHub Actions.

COMO USAR:
- Coloque os arquivos no repositorio respeitando as pastas.
- No GitHub, abra Actions > Gerar Juh Quiz Trend > Run workflow.
- Ao finalizar, baixe o artifact JUH-QUIZ-TREND.

MODO TAREFA COM ANTES/DEPOIS:
- Crie a pasta assets.
- Adicione assets/antes.png e assets/depois.png.
- Em campanha.py use:
  "intro_tipo": "antes_depois",
  "intro_imagem_1": "assets/antes.png",
  "intro_imagem_2": "assets/depois.png"

IMPORTANTE:
- O gerador visualiza a hashtag e cria abertura de campanha.
- Se a tarefa exigir que voce apareca, transforme o cabelo, use um look etc.,
  as imagens/video usados na abertura devem realmente mostrar essa acao.
